# Drafter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Drafter, a PDIS tool that suggests iTPP targets per variable from cited comparable-product evidence and published guidance, with browser-side review and a Word table export.

**Architecture:** A new stateless service `services/drafter` (variables → optional draft reading → search planning → Searcher retrieval → evidence reading → deterministic statistics → suggestion), exposed through `/api/drafter/run` (NDJSON) and `/api/drafter/export` (DOCX), consumed by a `/drafter` page built from the suite's shared components. Only the pure statistics move to `shared/statistics.py`; Scout imports them and is otherwise untouched.

**Tech Stack:** Python 3.11, FastAPI, Pydantic, python-docx, OpenAI via `shared/openai_client.py`; Next.js/React/TypeScript, node:test.

**Spec:** `docs/superpowers/specs/2026-10-21-drafter-design.md`

## Global Constraints

- Imports flow web → api → services → shared; Drafter uses Searcher and Chunker only through their packages.
- Every model stage is schema-bound (`shared.ai.request_structured`); one decision per request, declared in an `<ITEMS>_PER_REQUEST` constant with its reason.
- A model outcome (`insufficient`) and a pipeline failure (`status: failed` + code) never share a value; failed variables stay in the result.
- A suggestion cites only IDs the run holds; code checks IDs and exact quote existence, never prose meaning.
- Numbers for statistics only from verbatim excerpts in literature/registry/regulatory lanes; units never converted.
- Curated guidance values are transcribed by hand only; shipped configs contain none.
- OpenAI only. No priority card, no scores, no verdict vocabulary.
- Tool card copy: one sentence, 12–24 words, no authority clause, no negative clause.
- Saved result: `ANALYSIS_VERSIONS.drafter = 1`, one contract run on pack and unpack.

## Review Focus

- A finding with no excerpt, or an excerpt the model's quote does not appear in → observation dropped, never cited.
- Observations in two units (e.g. "%" and "per 1000") → two statistics groups, never pooled.
- Every source failing for a variable → suggestion still attempted on guidance alone or returns insufficient; result lists the failed sources.
- An uploaded draft that states every variable → no retrieval at all; run completes quickly.
- Finalize with an undecided suggestion → refused with a message; an edited value survives export.
